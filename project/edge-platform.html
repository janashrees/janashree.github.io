Automated Edge Deployment Platform

Capstone Project • Spring 2025

Overview

Designed a full-stack deployment and monitoring system for edge devices using Tailscale, Docker, and Prometheus-style metrics. Built real-time dashboards and alerting to improve observability in constrained environments.

Docker Tailscale WireGuard Prometheus Linux Vue (Dashboard)

What I Built

  • Zero-touch device onboarding flow using Tailscale registration and secure remote access.
  • System monitoring pipeline (CPU, memory, disk, services) with alert-ready metrics.
  • Dashboard-friendly endpoints powering real-time status views and health checks.

Impact

  • Improved reliability of edge deployments through faster debugging and clear system visibility.
  • Reduced manual setup steps by automating secure connectivity and key management.
