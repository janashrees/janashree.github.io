Linux Kernel Module – Disk Caching

Operating Systems Project • Fall 2024

Overview

Implemented a Linux kernel module simulating disk block caching behavior to analyze I/O performance improvements under repeated access workloads.

C Linux Kernel I/O Scheduling Virtual Machines

What I Built

  • Implemented kernel-space data structures to track cached disk blocks.
  • Hooked into block device read paths to intercept repeated accesses.
  • Logged cache hit/miss statistics via kernel logging.
  • Tested behavior under synthetic workloads in UTM Linux VM.

Impact

  • Observed measurable reduction in repeated disk access latency.
  • Gained hands-on experience with kernel synchronization and memory management.
