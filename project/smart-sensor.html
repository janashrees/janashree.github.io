Smart Sensor Simulator & IoT Dashboard

IoT & Web Systems Project • Spring 2025

Overview

Built a simulated embedded sensing platform that streams environmental telemetry to a cloud-style backend, with real-time visualization through a React-based dashboard.

Python Flask HTTP APIs React Data Visualization

What I Built

  • Created Python scripts to simulate temperature, gas, and vibration sensors.
  • Implemented REST APIs for ingesting telemetry data.
  • Designed live-updating charts on frontend dashboard.
  • Handled polling and refresh logic for near real-time updates.

Impact

  • Demonstrated full-stack IoT data pipeline from sensor to dashboard.
  • Enabled testing of analytics logic without physical hardware.
